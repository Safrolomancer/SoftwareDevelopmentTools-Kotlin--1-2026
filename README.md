# Software Development Tools

This repository contains my coursework, exercises and practical work for the **Software Development Tools** module at South East Technological University (SETU).

## Module Content

The repository contains Kotlin projects and exercises completed throughout the module.

Topics covered include:

- Kotlin fundamentals
- Variables and data types
- Functions
- Control flow
- User input
- Git
- GitHub
- Markdown
- Gradle
- Version control workflows

## Purpose

The purpose of this repository is to store and track my work for the Software Development Tools module and practise software development tools such as Git, GitHub, Kotlin and Gradle.

## Getting Started

1. Clone the repository.
2. Open the required project in IntelliJ IDEA.
3. Make sure the required JDK is installed.
4. Run the Kotlin project using IntelliJ IDEA or Gradle.
